# v2.0 — Git Entegrasyonu

## Özet

Session'ları o anda yapılan git commit'leriyle ilişkilendir. Commit başına tahmini süre görünümü sağlar. Tüm işlem lokaldir; ağ çağrısı yapılmaz.

## Adım 1 — Veri Katmanı

### Schema v2

`Session` arayüzüne opsiyonel `commits?: string[]` alanı eklendi. `schemaVersion` `1`'den `2`'ye yükseltildi. Migration non-destructive: mevcut session'lara `commits: []` atanır.

### `src/gitTracker.ts`

Çift mekanizma ile commit algılama:

- **Birincil:** `vscode.git` dahili extension API — `repo.state.onDidChange` event'i, `HEAD.commit` hash karşılaştırmasıyla yeni commit'i ayırt eder
- **Fallback:** `FileSystemWatcher` ile `.git/COMMIT_EDITMSG` değişikliği izlenir; `git log --format=%H -1` ile hash okunur

Her iki yolda da deduplication uygulanır: aynı hash tekrar `onCommit` callback'ine iletilmez.

### `src/sessionManager.ts` — `recordCommit(hash)`

Gelen hash'i aktif session'ın `commits[]` dizisine ekler. Idempotent: aynı hash ikinci kez eklenmez. Session yoksa sessizce döner.

### `src/extension.ts`

`startSession` çağrısından sonra `createGitTracker` başlatılır, dönen disposable `context.subscriptions`'a eklenir. VS Code deactivate sırasında otomatik temizlenir.

## Adım 2 — Summary Panel Commit Görünümü

### `src/views/summaryPanel.ts`

Son 10 tamamlanmış session için `resolveCommitMessages()` ile commit mesajları çekilir. `git log --no-walk --format=%H|%s` komutu batch olarak çalıştırılır; her satır `hash|mesaj` formatındadır.

### Webview

Session satırına genişletilebilir commit listesi eklendi: kısa hash (7 karakter) + commit mesajı. Boş `commits` dizisi olan session'larda commit satırı görünmez.

### `media/summary.js` / `media/summary.css`

CSP-uyumlu event delegation ile toggle mantığı. Inline event handler kullanılmaz.

## Adım 3 — Git Zaman Çizelgesi

### Komut: `devchrono.showGitTimeline`

Tüm session'lardaki commit hash'leri toplanır, `resolveCommitInfo()` ile git'ten hash + mesaj + tarih bilgisi çekilir, commit tarihine göre azalan sırada tablo olarak gösterilir.

`resolveCommitInfo()` kullanımı: `git log --no-walk --format=%H|%aI|%s` (hash | ISO tarih | mesaj)

### `src/views/gitTimelinePanel.ts`

`summaryPanel.ts` ile aynı `createOrShow` pattern'i. `logStorage.readLog()` üzerinden veri okur; `sessionManager`'a bağımlılık yoktur.

Git olmayan workspace: "git deposu bulunamadı" mesajı gösterilir, extension crash etmez.

### `media/timeline.css` / `media/timeline.js`

Tablo render, boş durum (hiç commit yok) ve git-yok durumu için ayrı şablonlar.

## Önemli Tasarım Kararı

**Süre = "Bu commit'in yapıldığı oturumda harcanan toplam süre."** Commit başına kesin attribution iddiasında bulunulmaz. Başlık her zaman bu şekilde etiketlenir.

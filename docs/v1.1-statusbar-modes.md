# v1.1 — Status Bar Gösterim Modları

## Özet

Kullanıcı, VS Code ayarlarından status bar'da hangi sürenin gösterileceğini seçebilir. Ayar değiştirildiğinde status bar anında güncellenir.

## Eklenen Ayar

`devchrono.statusBarMode` — üç seçenek sunar:

| Değer | Açıklama |
|-------|----------|
| `total` | Tüm zamanların kümülatif toplamı (varsayılan) |
| `today` | Yalnızca bugün harcanan süre |
| `session` | Yalnızca aktif oturumun süresi |

## Önemli Davranış

- Ayar değiştirildiğinde `onDidChangeConfiguration` event'i yakalanır ve status bar **anında** yeniden hesaplanır; bir sonraki 60 saniyelik tick beklenmez.
- `session` modunda aktif oturum yoksa (workspace açılır açılmaz kısa süre) status bar `⏱ 0s` gösterir.
- Ayar yoksa (yeni kurulum) `total` varsayılan olarak kullanılır.

## Dosyalar

| Dosya | Değişiklik |
|-------|-----------|
| `src/sessionManager.ts` | `updateStatusBar()` fonksiyonu moda göre hesaplama yapar |
| `package.json` | `contributes.configuration` altına `devchrono.statusBarMode` tanımı eklendi |

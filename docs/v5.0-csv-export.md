# v5.0 — CSV Export

> **Status:** Ready for implementation  
> **Session date:** 2026-04-28

---

## Feature Overview

Allow users to export all session data to a CSV file. Covers the billing and invoicing gap: developers can share time data with clients or import into spreadsheets without manual copy-paste.

**Scope:** Export all sessions from the current workspace's `time-log.json`. No date range filter in v5.0 (deferred to v5.1+).

---

## Architecture Decisions

- **New module:** `src/exportLog.ts` — owns CSV formatting and file write
- **New command:** `devchrono.exportLog` registered in `extension.ts` and `package.json`
- **File picker:** `vscode.window.showSaveDialog` with `.csv` filter
- **No external dependencies** — `Array.map` + `.join(',')` is sufficient for well-formed CSV

---

## CSV Schema

| Column | Source | Format |
|--------|--------|--------|
| `date` | `session.startTime` | `YYYY-MM-DD` |
| `project` | `log.projectName` | string |
| `branch` | `session.branch` | string (empty if non-git) |
| `start` | `session.startTime` | ISO 8601 local |
| `end` | `session.endTime` | ISO 8601 local |
| `duration_min` | `session.duration` | `Math.round(duration / 60)` |
| `active_min` | `session.activeSeconds` | `Math.round(activeSeconds / 60)` (if present, else same as duration_min) |
| `source` | `session.source` | `"pomodoro"` or `""` |

## User Story

**As a freelancer,**  
I want to export my workspace time log to CSV,  
So that I can build invoices or import into billing tools.

**Acceptance Criteria:**
- [ ] `devchrono.exportLog` opens a save dialog with `.csv` default filter
- [ ] Exported CSV has header row + one row per completed session
- [ ] Active (in-progress) session is excluded from the export
- [ ] If no sessions exist, show informational message and cancel
- [ ] On success, show "Exported N sessions to {path}" notification

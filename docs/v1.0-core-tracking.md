# v1.0 — Temel Zaman Takibi

## Özet

Session tabanlı zaman takibi. Workspace açıldığında sessizce başlar, kapandığında kaydeder. Kullanıcı herhangi bir işlem yapmaz; tüm kayıt arka planda gerçekleşir.

## Teslim Edilen Özellikler

- **Session yönetimi:** `startSession` / `endSession` / heartbeat her 5 dakikada bir yazar
- **Orphan session recovery:** Extension yeniden başladığında `endTime` olmayan session'lar `lastHeartbeat` zamanı kullanılarak kapatılır, `recovered: true` olarak işaretlenir
- **`.vscode/time-log.json` depolama:** Workspace-local, atomic write (tmp → rename) ile veri bütünlüğü korunur
- **Status bar göstergesi:** `⏱ Toplam: Xs Ydkk` formatında, her 60 saniyede güncellenir, tıklanabilir
- **Summary Panel webview:** Toplam / Bugün / Bu Hafta / Bu Ay özet istatistikleri + son 7 gün bar chart
- **Komutlar:** `devchrono.showSummary`, `devchrono.showToday`, `devchrono.resetLog`
- **Schema versiyonlama:** `schemaVersion: 1`, ilerisi için migration altyapısı hazır

## Veri Modeli (v1)

```typescript
interface Session {
  id: string;           // UUID
  startTime: string;    // ISO 8601
  endTime: string;      // ISO 8601
  duration: number;     // saniye cinsinden
  lastHeartbeat: string;// ISO 8601
  recovered: boolean;
}

interface ProjectLog {
  schemaVersion: number; // 1
  projectName: string;
  projectPath: string;
  createdAt: string;
  sessions: Session[];
}
```

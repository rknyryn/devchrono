# v5.2 — Pomodoro Stats in Summary Panel

> **Status:** Ready for implementation  
> **Session date:** 2026-04-28

---

## Feature Overview

Add Pomodoro-specific statistics to the summary panel. Shows how many Pomodoro work sessions were completed today and this week, and their total focused time. This closes the visibility gap: users using Pomodoro mode had no way to review their focus history.

---

## Architecture Decisions

### Schema Change — `source` field

Add optional `source?: 'pomodoro'` field to the `Session` interface in `logStorage.ts`.  
This is **backward compatible** — old sessions without the field default to regular sessions.  
**No `schemaVersion` bump needed** — optional additive field, not a breaking change.

### Session Tagging

- Add `tagCurrentSession(source: string)` to `sessionManager.ts` — sets `source` on the current in-memory session and persists.
- Call it in `pomodoroManager.ts` immediately after `startSession(context)` in `startWorkPhase()`.
- Pomodoro break sessions have no DevChrono session — only work phases are tagged.

### Stats Computation

In `summaryPanel.ts`, from completed sessions with `source === 'pomodoro'`:
- `pomodoroToday` — count today
- `pomodoroWeek` — count this week
- `pomodoroTimeToday` — total duration (seconds) today
- `pomodoroTimeWeek` — total duration (seconds) this week

These are added to `SummaryData` and rendered in `summary.js`.

## UI

A new "Pomodoro" section appears in the summary panel **below** the stats grid, **above** the 7-day chart:

```
🍅 Pomodoro İstatistikleri
────────────────────────────────
Bugün:    3 pomodoro  (1s 15dk)
Bu Hafta: 12 pomodoro (5s 0dk)
```

- Hidden if `pomodoroToday === 0 && pomodoroWeek === 0` (no pomodoro history)

## User Story

**As a developer using Pomodoro mode,**  
I want to see how many Pomodoros I completed today and this week,  
So that I can track my focus discipline over time.

**Acceptance Criteria:**
- [ ] Summary panel shows Pomodoro section when ≥1 pomodoro session exists
- [ ] "Bugün" shows count and total time for today's pomodoro sessions
- [ ] "Bu Hafta" shows count and total time for this week's pomodoro sessions
- [ ] New Pomodoro work sessions are tagged with `source: 'pomodoro'` in the log
- [ ] Old sessions without `source` are unaffected (treated as regular)
- [ ] Section is hidden when no pomodoro sessions exist (non-Pomodoro users see no change)

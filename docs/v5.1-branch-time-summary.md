# v5.1 — Branch Time Distribution

> **Status:** Ready for implementation  
> **Session date:** 2026-04-28

---

## Feature Overview

Add a visual "Branch Distribution" section to the summary panel. The existing "Dal Özeti" section shows collapsible branch groups with per-session detail. This new section shows an at-a-glance horizontal bar chart of how total time is distributed across branches.

**Goal:** Without expanding any accordion, the user sees which branches consumed the most time.

---

## Architecture Decisions

- **No new data** — `branchGroups` (already computed in `summaryPanel.ts`) carries `totalSeconds` per branch. No backend changes needed.
- **Client-only rendering** — `summary.js` renders the bar chart from the same `branchGroups` data already received.
- **Capped at top 8 branches** — prevents long lists; a "show all" expansion is a future enhancement.
- **Relative bars** — bar width = `(branch.totalSeconds / maxBranchSeconds) * 100%`

---

## User Story

**As a developer,**  
I want to see at a glance which branches I spent the most time on,  
So that I can understand my focus areas without expanding each branch section.

**Acceptance Criteria:**
- [ ] A "Branch Dağılımı" section appears above Dal Özeti when there are ≥2 branches
- [ ] Section is hidden when there's 0 or 1 branch (not useful for single-branch projects)
- [ ] Bars are proportional to relative time (widest = most time)
- [ ] Each row shows: branch name, bar, formatted total time
- [ ] Adapts to VS Code light/dark theme

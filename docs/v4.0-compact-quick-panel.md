> **Status:** Planning — ready for implementation  
> **Session date:** 2026-04-28

---

## Feature Overview

Kullanıcı status bar'a tıkladığında tam ekran özet açmak yerine **küçük bir kompakt panel** açılacak. Bu panel:

- Günlük / haftalık özet istatistiklerini kart formatında gösterir
- Pomodoro durumunu ve kontrol butonlarını barındırır
- "Detaylı Özet" linki ile mevcut `SummaryPanel`'e geçiş imkânı sunar

**Hedef:** Kullanıcı akışını kesmeden, bir bakışta durum görme + Pomodoro yönetimi.

---

## Architecture Decisions

### 1. Module Boundaries

```
extension.ts
  → quickPanel.ts       (status bar click → QuickPanel.createOrShow)
  → summaryPanel.ts     (QuickPanel içindeki "Detaylı Özet" linki çalıştırır)

quickPanel.ts
  → logStorage.ts       (summary verilerini okur)
  → pomodoroManager.ts  (durum bilgisi: isPomodoroActive, getPomodoroStatusText)
  → extension.ts        (webview mesajları → commands execute)
```

**`sessionManager.ts` ve `pomodoroManager.ts` doğrudan değişmez.** QuickPanel sadece okuma yapar veya mevcut `vscode.commands.executeCommand` ile iletişim kurar.

### 2. Panel Türü: WebviewPanel (Compact)

VS Code'da gerçek anlamda "floating popup" desteği yok. En uygun yaklaşım:

- `vscode.window.createWebviewPanel` ile `ViewColumn.Two` veya `ViewColumn.Beside`
- Küçük, kompakt HTML layout (card grid + buton satırı)
- `retainContextWhenHidden: false` — odak kaybında panel içeriği drop edilir, kaynak tüketmez
- Panel kapanınca `currentPanel = undefined` ile singleton temizlenir
- Aynı anda birden fazla açılmaz (singleton pattern — `SummaryPanel` ile aynı yaklaşım)

> **Alternatif değerlendirme:** `QuickPick` API kullanılabilir ancak özel kart tasarımı ve butonlar için WebviewPanel zorunlu.

### 3. Status Bar Click Değişikliği

Mevcut davranış: status bar tıklanınca `devchrono.showSummary` → `SummaryPanel` açılır.

Yeni davranış:
- Status bar tıklanınca `devchrono.showQuickPanel` → `QuickPanel` açılır
- `devchrono.showSummary` komutu var olmaya devam eder (Command Palette erişimi)
- QuickPanel içindeki "Detaylı Özet →" butonu `showSummary`'yi tetikler

### 4. QuickPanel İçerik Yapısı

```
┌─────────────────────────────────┐
│ ⏱ DevChrono          [✕ kapat] │
├─────────────────────────────────┤
│ [Bugün: 2s 14dk] [Bu Hafta: 8s] │
│ [Mevcut Oturum: 42dk]           │
├─────────────────────────────────┤
│ 🍅 Pomodoro                     │
│ [Başlat]  ← idle ise            │
│ [🍅 18:32 ▶ Durdur] ← aktifse  │
│ [☕ 4:12 ▶ Atla]   ← moladaysa │
├─────────────────────────────────┤
│ [📊 Detaylı Özet →]             │
└─────────────────────────────────┘
```

### 5. Veri Akışı

- Panel açılınca `readLog()` çağrılır → today/week/session hesaplanır
- Pomodoro durumu: `isPomodoroActive()` + `getPomodoroStatusText()` çağrılır
- Webview her **15 saniyede** kendini `pomodoroTick` mesajıyla günceller (sadece pomodoro sayacı)
- Komut mesajları (`startPomodoro`, `stopPomodoro`, `skipBreak`, `showSummary`) webview → extension host → `vscode.commands.executeCommand` ile işlenir
- Komut tamamlandıktan sonra panel yeniden `postMessage` ile güncellenir

## Webview Mesaj Protokolü

### Extension → Webview (postMessage)

```typescript
// İlk yükleme veya güncelleme
{ type: 'update', data: QuickPanelData }

// Pomodoro tick (15s aralıkla)
{ type: 'pomodoroTick', text: string, phase: 'idle' | 'work' | 'break' }
```

### Webview → Extension (onDidReceiveMessage)

```typescript
{ command: 'startPomodoro' }
{ command: 'stopPomodoro' }
{ command: 'skipBreak' }
{ command: 'showSummary' }   // → SummaryPanel açar, QuickPanel kapanır
{ command: 'close' }         // → panel.dispose()
```

---

## QuickPanelData Tipi

```typescript
interface QuickPanelData {
  projectName: string;
  today: number;        // seconds
  thisWeek: number;     // seconds
  currentSession: number; // seconds (aktif oturum)
  pomodoroText: string; // "🍅 18:32" veya "☕ 4:12" veya ""
  pomodoroPhase: 'idle' | 'work' | 'break';
}
```

## Stil Kararları

- VS Code tema token'ları kullanılır (`var(--vscode-*)`)
- Minimum genişlik: ~320px, maksimum: ~400px
- 3 kart satırı (istatistikler) + pomodoro bölümü + footer link
- `media/summary.css` referans alınır ama ayrı dosyada tutulur (panel bağımsız olmalı)
- Font: `var(--vscode-font-family)`

## Implementation Notes

- `pomodoroManager` döngüsel bağımlılık oluşturmasın diye `quickPanel.ts` sadece `isPomodoroActive()` ve `getPomodoroStatusText()` fonksiyonlarını import eder
- `extension.ts`'te `statusBar.command` değeri `devchrono.showQuickPanel` olarak güncellenir
- QuickPanel `dispose` edilince `currentPanel = undefined` set edilmeli (break panel ile aynı pattern)
- İlk açılışta `postMessage` bir `ready` sinyali ile tetiklenir; extension host `update` mesajı gönderir
